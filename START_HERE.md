# Движ 3.9.0 · Начало

1. Установите dist/dvizh-3.9.0-arm64.apk поверх прежней предварительной сборки без удаления.
2. Откройте «Настройки → Цели и расстояние». При необходимости измените длину шага и цели.
3. Проверьте сохранность шагов, воды и тренировок, затем виджет без нажатия.
4. Для GitHub используйте GITHUB_RELEASE.md. Не удаляйте .git и не запускайте git init повторно.

В архиве нет ключей подписи, SDK, кешей и локальных паролей.
