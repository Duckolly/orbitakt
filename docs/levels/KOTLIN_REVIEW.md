# Аудит переданных исправлений

Переданы DailyStepService и DailyStore; оригиналы сохранены в supplied/.
Внедрена адаптированная версия, без удаления шагов и без изменений схемы БД.

1. Стабильное давление <0.02 hPa НЕ доказывает движение транспорта.
   Эта ветка помечала бы обычную ходьбу по ровной поверхности. Дополнительная
   подписка на барометр исключена; существующий модуль барометра не менялся.
2. Датчик приближения НЕ определяет телефонный звонок. Он может срабатывать
   в кармане. Метаданные только отмечают крупный пакет >20 шагов как
   приблизительный; шаги никогда не вычитаются и не отвергаются.
3. Состояние приближения не приписывается задержанным пакетам старше 2 секунд.
4. Подписка на приближение запускается только после успешной подписки на шаги;
   отключается вместе с ней. Новых разрешений и сервисов нет.
5. Защита типа события: посторонний датчик не попадёт в накопительный счётчик.
6. Исходная sample(raw, timestampMillis) сохранена, добавлена перегрузка.
   DailyStore version=1 и формат дней/итогов сохранены. fromVehicle отключён,
   параметр оставлен для совместимости с предоставленным исправлением.

Ограничение: это не фильтр ложных шагов. Для надёжного распознавания поездок
нужны другие данные/алгоритм и испытания на телефонах. Без такого основания
подменять реальные итоги предположением нельзя.

Проверки: StepSampleQualityTest плюс прежние Kotlin тесты, release build/lint.
Итоговые фактические статусы находятся в TASKS.md и VALIDATION.md.
