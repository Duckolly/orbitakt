# Готовность 3.5

Исходники, оптимизированный ARM64 release-preview APK, инструкции и два визуальных превью включены. Flutter analyze, 36 Flutter и 16 Kotlin тестов, Android Lint release, APK/подпись/permissions/16KB проходят. Тестовая установка — отдельный package; обновление основного приложения пока блокируется отсутствием прежнего ключа. Оригинальная фирменная иконка требует PNG/ZIP. Реальная приёмка этой версии на телефоне ещё не выполнена.
