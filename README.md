# Движ 3.8.0 — батарея и нагрузка

Готовый ARM64 APK: dist/dvizh-3.8.0-arm64.apk в полном ZIP. Исходники для Git
предоставляются отдельным архивом без APK и секретов. Инструкция: GITHUB_RELEASE.md.

Добавлен ручной замер батареи всего телефона, состояние Android и время выбранных
модулей Движа. Постоянного опроса, новой службы и новых разрешений нет.
Подробнее: docs/BATTERY.md и RELEASE_NOTES_3.8.0.md.

## Обновление и статус выпуска

Устанавливать поверх ранее выданного «Движ · тест» 3.5/3.6/3.7. Пакет остаётся
`com.duckolly.dvizh.preview`, сертификат тот же, versionCode 10. Прежние данные сохраняются в том же пакете. Основная старая установка `com.duckolly.dvizh` имеет
отдельные записи. Переименование не переносит историю между пакетами.

Пользователь сообщил об установке, просмотре интерфейса и положительном результате
предыдущей версии; это зафиксировано в TASKS.md. Точность сенсоров, ночного неба,
расход батареи и обновление именно этой сборкой на телефоне ещё требуют контроля.

Текущее название уже без «тест». Подготовка магазинного выпуска — отдельный этап:
постоянная подпись, кабинет издателя, финальные документы/карточка и пилот.
Сборка использует сохранённую подпись разработки и не обозначается как готовая
к загрузке в магазин. См. docs/RELEASE_STATUS.md.

## Проверки

Результаты проверки этой сборки: docs/VERIFICATION_3.8.0.md.
Проверены реальные подпись, package, code10, название «Движ», точные прежние
разрешения, CRC, 16KB, каталоги и лицензии. Сверены исходники и сборка.
Превью масок — кодовый рендер, не снимок launcher на OnePlus. SDK, приватный
ключ и машинные настройки не включены в архив.

Шаги, вода, виджет, Бегалка/наклон, дыхание, перепад высоты и Ночное небо сохранены.
Таймер разминки исключён из очереди. Инструкции: START_HERE.md, TASKS.md,
docs/NIGHT_SKY.md, docs/BATTERY.md, docs/VERIFICATION.md.
