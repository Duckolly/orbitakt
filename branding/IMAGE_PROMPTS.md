# Иконка: происхождение и подготовка

Режим: встроенная генерация изображений. Новый дизайн показан и утверждён пользователем 02.11.2026. Утверждённый мастер: DVIZH_Approved_Icon.png. Для адаптивного слоя в APK используется воспроизводимая нативная векторная адаптация из Android XML и DVIZH_Adaptive_Icon.svg. Legacy/Store PNG — экспорты утверждённого мастера, без изменения композиции.

Исходное задание: один квадратный значок Android для ДВИЖ. Тёмный индиго/сливовый фон с мягким градиентом; одна крупная геометрическая кириллическая Д с двумя короткими ножками, небольшим наклоном вперёд и контрастным фиолетово-лавандовым градиентом. Крупные простые детали, запас для круглых/скруглённых масок и читаемость на 48 px. Без надписей, дополнительных пиктограмм, фототекстуры, свечения, объёмных эффектов и встроенных скруглённых углов.

Подготовка Android: отдельные background/foreground, безопасная область, monochrome для Android 13+, legacy плотности и круглая совместимая иконка. Превью масок — кодовый рендер SVG для проверки, не снимок launcher на телефоне. Системная форма и тематический цвет зависят от настроек устройства.
