# Движ 3.8.2+12 — обновление виджета

Исправлено: минутный лимит обновлений терял последний итог короткой прогулки.
Вместо отбрасывания запросов используется очередь с одним отложенным обновлением.
Повторные события не откладывают его бесконечно; сбросы/вода публикуются сразу.

Когда телефон интерактивен, данные сенсора запрашиваются без намеренного
пакетирования, а обновления виджета объединяются в интервал5секунд. При выключенном
экране без тренировки остаётся60секунд пакетирования для экономии энергии.
При активации экрана обновление и flush сенсора запрашиваются без нажатия на виджет.
Доставка всё равно зависит от сенсора, Android и лаунчера; мгновенность не обещается.

Новых разрешений, отдельных служб, периодического опроса, wake lock и сетевых
запросов нет. Алгоритмы распознавания шагов и хранение истории не менялись.
Погрешность на OnePlus пока не измерена: см.docs/STEP_ACCURACY.md.
