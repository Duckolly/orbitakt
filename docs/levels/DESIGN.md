# Оформление окон

Ориентир: Material Cards (изображение, заголовок, значение, действия):
https://github.com/material-components/material-components-android/blob/master/docs/components/Card.md
https://m3.material.io/components/cards/overview
Референсы изучены 2026-11-05. Код и иллюстрации сторонних приложений не копировались.

Сегодня: крупное число на тональной карточке, прежние элементы управления.
Текущий месяц: число/среднее, название уровня, изображение, 5 доступных отметок.
Зверинец: отдельный завершённый месяц; фиксируется первый просмотр месяца.
Раскрываемый список всех уровней. Светлая/тёмная темы, перенос длинного текста.
Новые изображения добавлены только в assets/ranks; библиотеки не добавлялись.
pubspec: единственное изменение — регистрация каталога assets/ranks/.
Ни версия pubspec, ни Gradle, ни Manifest, ни package ID не изменены.

Картинки пользователя сохранены с исходными пикселями через lossless WebP.
Пять отсутствовавших изображений созданы с разрешения пользователя, без надписей:
синий кит (5), заяц (2), обезьяна (3), эму (4), динозавр (5).
Промпт: квадратный рисованный значок животного, тёмный контур, цветная медаль
с металлической рамкой и соответствующим числом звёзд; без букв, цифр и предметов туалета.
