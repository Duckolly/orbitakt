# Границы ДВИЖ 3.4.0

Android-приложение для локальных тренировок и опционального дневного шагомера. Данные остаются у пользователя; общего рейтинга, групп, аккаунтов, сервера и корпоративного сбора нет. Дневной режим использует health foreground service, системный счётчик и отдельную SQLite.

Тренировка вне приложения ставится на паузу, дневная служба продолжает доступный ОС учёт. Система может прервать процесс; перезагрузка требует возобновления. Обход пользовательской остановки и автозапуск BOOT не реализованы.

Исторические сообщения и генераторы относятся к предыдущим вариантам продукта; не накладывать их поверх 3.4.0. Публикация сайта, аккаунт разработчика, постоянная подпись, маркетплейсы и утверждённые растры бренда — отдельные задачи владельца. Сайт в site/ обновлён как комплект исходных материалов, но не опубликован.

## Дополнение 3.4

Ручной журнал воды по 200 мл и нативный виджет шаги/вода реализованы. API 37 MetricStyle, Live Updates, Health Connect, плитка быстрых настроек и выпуск магазина не реализованы.
