## Обновление и статус выпуска

Устанавливать поверх ранее выданного «Движ · тест» 3.5/3.6/3.7. Пакет остаётся
`com.duckolly.dvizh.preview`, сертификат тот же, versionCode 12. Прежние данные сохраняются в том же пакете. Основная старая установка `com.duckolly.dvizh` имеет
отдельные записи. Переименование не переносит историю между пакетами.

Пользователь сообщил об установке, просмотре интерфейса и положительном результате
предыдущей версии; это зафиксировано в TASKS.md. Точность сенсоров, ночного неба,
расход батареи и обновление именно этой сборкой на телефоне ещё требуют контроля.

Текущее название уже без «тест». Подготовка магазинного выпуска — отдельный этап:
постоянная подпись, кабинет издателя, финальные документы/карточка и пилот.
Сборка использует сохранённую подпись разработки и не обозначается как готовая
к загрузке в магазин. См. docs/RELEASE_STATUS.md.
