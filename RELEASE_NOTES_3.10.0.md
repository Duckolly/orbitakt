# Орбитакт 3.10.0 · build 24

## Изменения

- Добавлены уровни для шагов и воды по среднему значению за день за выбранный
  период, а для туалета — по месячной сумме.
- Добавлен зверинец: лиса → волк → лев → пантера → дракон; выдра → дельфин →
  акула → косатка → синий кит; нейтральная иконка → заяц → обезьяна → эму →
  динозавр.
- Обновлены карточки шагов, воды и туалета; сохранены история и возможность
  отменить ошибочную запись.
- Окна проверены на малом экране, увеличенном тексте, темах, пустых данных
  и состояниях ошибки.
- Подписанный ARM64 APK для основной линии: `com.duckolly.dvizh`.

## Проверки

135 Flutter-тестов, 31 Kotlin release unit-тест, Flutter analyze, Android
release lint и 472 статические проверки прошли. Подпись, разрешения и
16-КБ выравнивание APK проверены. Физическая приёмка на телефоне ещё не
выполнена.
