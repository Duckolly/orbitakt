# ДВИЖ 3.3.0 / versionCode 3

Новый режим «Шаги за день» с системным датчиком и health foreground service, дневной историей, переключателем и Stop из уведомления. Шаги тренировок не суммируются с дневными повторно. Выключенный период не импортируется следующим включением.

Разрешения добавлены только для foreground service и его типа health; интернета/GPS/WakeLock/BOOT нет. Поддерживаются Android API 24+ при наличии системного счётчика; иначе доступны отдельные тренировки. Обновлены политика и инструкции.

18 Flutter + 12 Kotlin tests, Dart analyze, Android Lint и сборка APK прошли. Реальные экран-off/Doze/reboot/force-stop и батарея пока требуют device-приёмки. После перезагрузки — ручное возобновление; пропуски при остановках ОС возможны.
