# Движ 3.8.1+11 — О приложении и связь

В настройках появился раздел «О приложении и связь»:
- версия и номер сборки из установленного Android-пакета;
- автор: Сергей Швецов;
- сообщество Telegram: https://t.me/dvizhoffline;
- открытие Telegram/браузера по явному нажатию;
- копирование адреса, доступное без интернета;
- подсказка, какие сведения указать при сообщении об ошибке.

Адрес группы предоставлен владельцем проекта. Фактическая работа внешней ссылки
на телефоне требует проверки. При ошибке запуска адрес остаётся доступен для
копирования. Открытие ссылки не отправляет историю или диагностические данные.
При переходе во внешнее приложение действуют его правила обработки данных.

Новых разрешений, зависимостей, фоновых служб и автоматических запросов нет.
Шагомер, вода, игры, небо и модуль батареи сохранены. Подпись разработки и пакет
com.duckolly.dvizh.preview прежние, versionCode увеличен до11. Устанавливать поверх
3.8.0 без удаления приложения. Это APK для пилота/GitHub, не магазинный пакет.
