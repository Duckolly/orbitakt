# Начало работы с Орбитакт 3.9.5

1. Установить orbitakt_395_arm64.apk поверх 3.9.4 без удаления приложения.
2. Открыть «Подышать» → «Перед сном». Ритм начинается с 4/4 с, увеличение только после трёх комфортных завершённых занятий и нажатия «Увеличить».
3. Если ритм не подходит, выбрать короткие фазы, свободное дыхание или «Сделать проще». Дышать мягко, без усилий и задержек.
4. Для GitHub распаковать ZIP в корень настоящего репозитория (там, где .git). Вложенная папка app содержит pubspec.yaml версии 3.9.5+18. Не удалять .git и локальные ключи.
5. Инструкция публикации — GITHUB_RELEASE.md; изменения и ручная проверка — RELEASE_NOTES_3.9.5.md.

APK собран для ARM64, с тем же предварительным ключом и package com.duckolly.dvizh.preview. История шагов и воды не мигрируется и не очищается. Это предварительная сборка для прямой установки, не публикация в Google Play.
