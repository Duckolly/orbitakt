# Утверждённая иконка ДВИЖ

Пользователь утвердил показанный PNG 02.11.2026. DVIZH_Approved_Icon.png — неизменённый мастер. Legacy PNG — экспорт мастера со скруглённой системной маской; Store 512 — квадратный экспорт мастера. Для Android 8+ использована нативная векторная адаптация силуэта и градиента; для Android 13+ — отдельный monochrome слой в adaptive-icon. Неровные пробные прозрачные вырезки не включены в проект. DVIZH_Adaptive_Icon.svg воспроизводит цветные слои для проверки масок. Символ масштабирован в центральную безопасную область. Форма маски и цвет тематической иконки определяются launcher/настройками Android.
