## Критичные баги (блокируют работу)

### BUG-001: Ошибка интерполяции строк в activity_screen.dart 🔴
**Файл:** `app/lib/screens/activity_screen.dart`  
**Строка:** метод `_formatDuration`  
**Проблема:** В Python-скрипте символ `$` был экранирован как `\$`, в Dart-файл ушло `\$` вместо `$`. Это синтаксическая ошибка, приложение не скомпилируется.  
**Фикс:** Заменить `\$` на `$` в строке форматирования времени.  
**Тест:** Запустить приложение, начать тренировку, проверить отображение таймера.

### BUG-002: Нет запроса разрешений на Android 10+ 🔴
**Файл:** `app/lib/screens/activity_screen.dart`  
**Проблема:** На Android 10+ (API 29+) нужно явно запрашивать `ACTIVITY_RECOGNITION`. Без этого акселерометр не вернёт данные.  
**Фикс:** Добавить вызов `Permission.activityRecognition.request()` в `initState`.  
**Тест:** Установить на Android 11+, проверить, что шаги считаются.

## 🔧 Шаг 2: Фиксим первый критичный баг (BUG-001)

Откройте файл `app/lib/screens/activity_screen.dart` и найдите метод `_formatDuration`.

**Было (сломано):**
```dart
String _formatDuration(int seconds) {
  final h = seconds ~/ 3600;
  final m = (seconds % 3600) ~/ 60;
  final s = seconds % 60;
  return '\${h.toString().padLeft(2, '0')}:\${m.toString().padLeft(2, '0')}:\${s.toString().padLeft(2, '0')}';
}
```

**Замените на (исправлено):**
```dart
String _formatDuration(int seconds) {
  final h = seconds ~/ 3600;
  final m = (seconds % 3600) ~/ 60;
  final s = seconds % 60;
  return '${h.toString().padLeft(2, '0')}:${m.toString().padLeft(2, '0')}:${s.toString().padLeft(2, '0')}';
}
```

**Что изменилось:** Убрано экранирование `\$` → `$`. Теперь Dart корректно интерполирует переменные.
