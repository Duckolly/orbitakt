```markdown
# StepQuest: Концепция и MVP

## 🎯 Название проекта
**StepQuest** (Рабочее название: "ШагоКвест" / "ActiveTeam")

## 💡 Суть идеи (Elevator Pitch)
StepQuest — это офлайн-первый шагомер с элементами геймификации, который превращает обычную ходьбу в командные соревнования с реальными наградами. Мы не продаем "здоровый образ жизни", мы продаем **азарт, командный дух и бесплатные плюшки** (кофе, мерч, отгулы), за которые шаги обмениваются автоматически.

## 🚨 Проблемы, которые мы решаем
1. **Для пользователей:** Обычные шагомеры скучны, данные ни на что не влияют, мотивация падает через 2 недели.
2. **Для компаний (B2B):** Корпоративные программы wellness не работают, сотрудники игнорируют рассылки, растет выгорание и количество больничных.

## 🛠 Функционал MVP (Минимально жизнеспособный продукт)
### Для пользователя (Mobile App):
- **Офлайн-трекинг:** Считает шаги через акселерометр без интернета и GPS (экономия батареи).
- **Синхронизация:** При появлении интернета данные улетают на сервер для обновления рейтингов.
- **Командный режим:** Возможность вступить в "Отдел маркетинга" или создать свою лигу с друзьями.
- **Магазин наград:** Виртуальная валюта ("StepCoin"), которую можно обменять на реальные награды от партнеров (сертификат на кофе, футболка компании, дополнительный час обеда).

### Для администратора (Web Dashboard):
- Создание компании и приглашение сотрудников по ссылке/QR-коду.
- Настройка правил конвертации шагов в баллы.
- Загрузка каталога наград.
- Аналитика: общая активность компании, самые активные отделы.

## 🚀 Уникальное торговое предложение (УТП)
"Единственный шагомер, который окупает себя кофе и выходными, работая без интернета и не сажая батарею".
```

```markdown
# StepQuest: Бизнес-план и Монетизация

## 🎯 Целевая аудитория (ЦА)
1. **B2B (Основной фокус на старте):** Малый и средний бизнес (50–500 сотрудников). HR-директора и офис-менеджеры, ищущие недорогие способы повысить вовлеченность.
2. **B2C (Вторичный фокус):** Группы друзей, семьи, любители ЗОЖ, которым скучно ходить в одиночку.

## 💰 Модели монетизации
1. **B2B SaaS Подписка:** 
   - Тариф "Старт": 99 руб. / сотрудник / месяц (базовая аналитика, до 3 наград).
   - Тариф "Про": 199 руб. / сотрудник / месяц (кастомные лиги, API интеграция с HR-системами, неограниченные награды).
2. **B2C Premium:** 
   - 149 руб./мес или 990 руб./год (отключение рекламы, расширенная статистика здоровья, эксклюзивные аватарки).
3. **Affiliate (Партнерская комиссия):** 
   - Мы берем 10-15% комиссии с партнеров (кофейни, магазины спорттоваров), чьи сертификаты сотрудники выкупают за шаги. Для партнера это лидогенерация, для нас — доход.

## 📊 Финансовая модель (Прогноз на 1-й год)
- **Месяцы 1-3:** Разработка MVP, пилотный запуск в 3-х дружественных компаниях (бесплатно за кейс и отзыв). Затраты: только время разработки.
- **Месяцы 4-6:** Выход на 5 платящих компаний (в среднем по 100 чел). Выручка: ~50 000 руб./мес.
- **Месяцы 7-12:** Масштабирование через HR-сообщества. Цель: 20 компаний (2000 сотрудников). Выручка: ~300 000 руб./мес. + партнерские отчисления.

## ⚠️ Риски и их mitigation (снижение)
- **Риск:** Низкая точность шагомера на разных телефонах. 
  *Решение:* Использование калибровочного теста при первом запуске ("Пройди 20 шагов, мы настроим чувствительность").
- **Риск:** Компании не хотят платить за "игрушку".
  *Решение:* Продавать не игру, а "Снижение текучести кадров и улучшение климата в коллективе", подкрепляя это цифрами из пилотных кейсов.
```

```markdown
# StepQuest: Техническая архитектура и стек

## 📱 Мобильное приложение (Клиент)
- **Фреймворк:** Flutter (Dart). Позволяет написать один код для iOS и Android, экономя 40% времени разработки.
- **Датчики:** Пакет `sensors_plus` или нативные каналы (Kotlin/Swift) для доступа к `TYPE_STEP_COUNTER` (аппаратный шагомер Android) и `CMPedometer` (iOS). Это критически важно для работы в фоне и экономии батареи.
- **Локальное хранилище:** `sqflite` или `hive`. Все шаги сохраняются локально. Если интернета нет, приложение продолжает считать и кэшировать данные.
- **Фоновая работа:** Использование `workmanager` (Android) и `background_fetch` (iOS) для периодической синхронизации накопленных данных при появлении сети.

## ☁️ Бэкенд и База данных (Сервер)
- **BaaS (Backend as a Service):** Supabase или Firebase. 
  - *Почему:* Не нужно с нуля писать аутентификацию, базу данных и API. Это ускоряет запуск MVP в 3 раза.
  - *База данных:* PostgreSQL (в Supabase) для надежного хранения транзакций (шаги -> баллы).
- **Логика:** Cloud Functions (Firebase) или Edge Functions (Supabase) для ежедневного пересчета рейтингов и начисления баллов (чтобы не нагружать телефон пользователя).

## 🔒 Безопасность и Приватность (152-ФЗ / GDPR)
- **Анонимизация:** На сервер отправляются только: `User_ID` (хэш), `Дата`, `Количество_шагов`. Никаких GPS-треков, никаких имен файлов.
- **Согласие:** При первом запуске обязательный чекбокс "Я согласен на обработку обезличенных данных для участия в рейтинге".
- **Шифрование:** Передача данных только по HTTPS.

## 🗺 Дорожная карта разработки (8 недель)
- **Недели 1-2:** Прототип в Figma, настройка проекта Flutter, базовый счетчик шагов (офлайн).
- **Недели 3-4:** Интеграция Supabase, система регистрации, сохранение данных в облако.
- **Недели 5-6:** Геймификация: создание команд, таблица лидеров, начисление виртуальных баллов.
- **Недели 7-8:** Админ-панель для HR, тестирование на 5-10 разных устройствах, публикация в TestFlight / Google Play Internal Testing.
```
