# Орбитакт 3.9.5

Репозиторий: https://github.com/Duckolly/orbitakt . Тег: v3.9.5.

## Описание GitHub Release

- Режим «Перед сном» с ночным экраном и постепенным дыханием: 4/4 → 4,5/4,5 → 5/5 секунды, без задержек.
- После трёх комфортных завершённых занятий предлагается следующая ступень; увеличение только по нажатию. Есть «Оставить», «Сделать проще», свободный ритм и 4,5/5,5 с.
- Настройки 5/10/15 минут, отключаемые системные подсказки, локальное сохранение прогресса, пауза при сворачивании и блокировке экрана.
- Встроенная справка с источниками и ограничениями. Режим для расслабления, без обещаний накопить кислород или вылечить бессонницу.
- Сохранены 16+, фиолетовый котик, шаги, километры, вода и сайт с рассказом https://duckolly.github.io/testofsilence/ .

Установка поверх предыдущего предварительного APK без удаления приложения. Package и подпись сохранены. Подробности: RELEASE_NOTES_3.9.5.md.

## Исходники

Распаковать ZIP в корень существующего репозитория рядом с .git. Сохранить .git и локальные ключи. Проверить git diff --check и git status --short перед коммитом. Не менять Android package или ключ подписи ради переименования приложения.
