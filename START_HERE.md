# ДВИЖ 3.8.0 — быстрый старт

## Проверить на телефоне

В dist/ лежит dvizh-3.8.0-arm64.apk. Установить поверх preview 3.5.0/3.6.0/3.7.0/3.7.1 либо как отдельное приложение «Движ». Оно использует com.duckolly.dvizh.preview, свою историю и прежнюю preview-подпись. Старый ДВИЖ не обновляется. Этот APK предназначен для ARM64, включая OnePlus 15; x86-эмуляторы и 32-битные ARM не поддерживаются данным вариантом.

Новый виджет выбирать по имени «Движ: шаги и вода». Изменение старого виджета основного приложения требует обновления основного пакета с совместимой подписью.

## Собрать на ПК

Установить Flutter 3.35.7 (Dart 3.9.2), полный JDK17 с javac, Android SDK Platform36/Build-tools35.0.0; плагины используют Platform34/35, NDK27.0.12077973 и CMake3.22.1. Это зафиксированный набор проверки, не заявление о последних версиях инструментов. SDK/кэши не вложены. Для первой установки инструментов и загрузки зависимостей нужен интернет; приложение работает офлайн.

В app сначала flutter pub get --enforce-lockfile, flutter analyze --no-pub, flutter test --no-pub. Команды ARM64 release-preview и обычного release приведены в docs/BUILD_MODES.md. Сборка Windows напрямую не проверялась; сборка пакета выполнена на Linux.

Для будущего обновления preview использовать сохранённый preview-keystore через свойство dvizhPreviewKeystore. Не заменять им ключ основного приложения. Для основного release нужен android/key.properties с постоянной подписью владельца; без него release по умолчанию блокируется.

Утверждённая новая иконка подключена; исходный мастер и адаптивные ресурсы находятся в branding/ и app/android/app/src/main/res/.

Для публикации на GitHub: GITHUB_RELEASE.md. Новый экран: docs/BATTERY.md.
