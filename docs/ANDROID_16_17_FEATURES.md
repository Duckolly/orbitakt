# Возможности Android 16 и 17 — проверено 31.10.2026

Обзор официальной документации. ДВИЖ 3.4.0 собирается с compileSdk/targetSdk 36, minSdk 24. Наличие API в документации не означает, что текущий пакет уже использует API 37 или проверен на Android 17.

| Возможность | Польза | Решение |
|---|---|---|
| Стандартный виджет рабочего стола (доступен и до Android 16) | Шаги и вода без открытия приложения | Реализован: текст, +200/−200 мл, снимок с датой/временем |
| Android 17 Notification.MetricStyle, API 37 | До трёх показателей, например шаги и таймер активной тренировки | Кандидат следующей версии: нужен compileSdk 37, проверка поведения и fallback для старых ОС |
| Live Updates Android 16+, расширение MetricStyle в Android 17 | Заметное системное представление конкретной идущей тренировки | Для ограниченной по времени тренировки после отдельной реализации фонового режима; дневной счётчик воды туда не переносить |
| Адаптивный интерфейс для больших экранов Android 16/17 | Планшеты, складные телефоны, изменение размеров окна | Дальнейшая адаптация: две панели истории/итогов и проверка на реальных форм-факторах |
| Quick Settings tile (существует до Android 16) | Явный переход к включению/остановке режима | Небольшое возможное следующее улучшение; не добавлен в этой сборке |

## Энергия и ограничения виджета

Android поддерживает информирующие и управляющие app widgets. updatePeriodMillis имеет минимум 30 минут; обновления по пользовательскому действию доступны отдельно. Поэтому в этой версии нет секундного опроса, exact alarms или дополнительного service для воды. Обновления по шагам ограничены одной попыткой в минуту; если новых событий нет, специальный таймер не запускается. Периодические обновления могут задерживаться системой.

Android 17 ограничивает суммарную память Bitmap/Icon в RemoteViews для target 37. Наш виджет не создаёт Bitmap и использует текст/ресурсный shape. Фактический расход энергии пока не измерен.

## Live Updates и MetricStyle

MetricStyle добавлен в API 37 и отображает до трёх метрик. Это перспективно для активной тренировки: шаги и время. Продвижение в Live Update требует отдельного разрешения POST_PROMOTED_NOTIFICATIONS, запроса promotion и соответствия системным критериям. Нужна текущая, начатая пользователем и требующая своевременного внимания активность с началом/концом; решение также зависит от пользователя и OEM.

Наша оценка: виджет подходит для дневных шагов и воды; Live Update стоит внедрять после отдельного фонового режима конкретной тренировки. Сейчас тренировки ставятся на паузу вне приложения, поэтому объявлять постоянное активное уведомление тренировки было бы неверно. Новое разрешение в 3.4.0 не запрашивается.

## Google Play

Виджет — штатная возможность Android; наличие виджета само по себе не даёт гарантии модерации. Для текущего фитнес-приложения надо корректно заполнить Health apps declaration, декларацию foreground service и Data safety, опубликовать действующую HTML-политику с описанием шагов/воды/виджета и фактического локального хранения. В декларации следует отразить Activity and Fitness и проверить применимость Nutrition and Weight Management к журналу воды. Не выбирать «нет health-функций».

Тестовый debug APK предназначен для пилота. Для магазина нужен подписанный release AAB с постоянным ключом владельца и проверкой актуальных требований Play Console. Публикация, отправка деклараций и гарантия одобрения в задачу не входили. Health Connect сейчас не используется; возможную интеграцию нужно проектировать отдельно с добровольным разрешением и обновлением раскрытий.
