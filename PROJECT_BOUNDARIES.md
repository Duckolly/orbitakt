# Два независимых проекта

| Проект | Цель | Рабочая кодовая база |
|---|---|---|
| 01 ОСАГО | Поиск дел-кандидатов, ограниченный review и методология допуска данных | Python 3.11+ osago_tool |
| 02 ДВИЖ | Локальная запись физической активности на телефоне | Flutter/Dart app + Android + site |

Базы данных, ключи, модели и интеграции между проектами не разделяются. ОСАГО не является модулем трекера; трекер не имеет доступа к судебным данным.

EXTRACTION_MANIFEST.json фиксирует извлечённые версии, включая первоначальные пути и хеши до последующей консолидации. PACKAGE_MANIFEST.json фиксирует фактический итоговый состав и хеши; изменения/добавления при упаковке в нём отмечены отдельно.
