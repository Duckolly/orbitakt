# Орбитакт — история проверки и решения по названию

## Текущее решение, 03.11.2026

Владелец сообщил: слово «Орбитакт» в реестрах Роспатента свободно, затем прямо поручил сменить название в приложении и следующем патче. По этому поручению в 3.9.3 выполнено переименование отображаемых названий в «Орбитакт». Результат проверки передан владельцем; независимое подтверждение выдачи Роспатента в этой среде не получено, юридическая гарантия не заявляется.

## Предыдущие попытки, 03.11.2026

В 3.9.2 официальные поисковые формы не загрузились: https://searchplatform.rospatent.gov.ru/trademarks вернул ошибку веб-получения и пустую страницу в браузере; https://online.rospatent.gov.ru/panel не загрузился. Это не нулевая выдача. Тогда переименование было отложено. Этот прежний технический статус больше не является запретом на исполнение нового прямого поручения владельца.
