## 🐛 Что я уже нашёл в текущем коде (Code Review)

### Критичные баги (ломают функционал):

**1. Ошибка интерполяции в `activity_screen.dart`:**
```dart
// БЫЛО (сломано):
return '\${h.toString().padLeft(2, '0')}:\${m...}';
// ДОЛЖНО БЫТЬ:
return '${h.toString().padLeft(2, '0')}:${m.toString().padLeft(2, '0')}:${s.toString().padLeft(2, '0')}';
```
Я экранировал `$` в Python-строке, и в Dart-файл ушло `\$` — это синтаксическая ошибка.

**2. Не запрашиваются разрешения на Android 10+:**
В `pubspec.yaml` есть `permission_handler`, но в коде нет вызова `Permission.activityRecognition.request()`. На современных Android приложение просто не получит данные с акселерометра.

**3. Нет обработки пустых значений в настройках:**
Если пользователь очистит поле "Никнейм", в `SharedPreferences` запишется пустая строка, а в отчёте будет выглядеть некрасиво.

### Важные улучшения (качество и UX):

**4. Нет фонового режима** — главная проблема шагомера. Если пользователь свернёт приложение, подсчёт остановится. Нужно добавить `foreground service` (Android) и `BGTaskScheduler` (iOS).

**5. Нет сброса данных** — требование 152-ФЗ и GDPR. Пользователь должен иметь возможность удалить все свои данные одной кнопкой.

**6. Нет адаптивности под планшеты** — `GridView` с `crossAxisCount: 1` на планшете будет выглядеть странно.

**7. Нет тёмной темы** — сейчас модно и важно для battery-life на OLED.

**8. Нет accessibility** — для слабовидящих (semantic labels, scale text).

**9. Нет локализации** — только русский, а для App Store/Google Play нужен английский минимум.

**10. Нет unit-тестов** — без них любой рефакторинг может сломать функционал незаметно.
