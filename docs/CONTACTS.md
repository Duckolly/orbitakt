# Контакты 3.8.1

Настройки → О приложении и связь. Автор: Сергей Швецов.
Группа пользователя: https://t.me/dvizhoffline.

Версия читается из PackageManager; ссылка фиксирована в Android AboutBridge.
Произвольные адреса из MethodChannel не принимаются. ACTION_VIEW запускается
только по явному нажатию. Нет проверки ссылки или запроса в сеть при старте.
Без обработчика перехода показывается сообщение с предложением скопировать адрес.
Clipboard записывается только по нажатию. Новых разрешений и зависимостей нет.
Само приложение сохраняет офлайн-режим; внешнему Telegram/браузеру нужен интернет.

Приёмка на телефоне (ещё нужна):
1. Установить поверх3.8.0, проверить шаги/воду/историю.
2. Открыть настройки → раздел: версия3.8.1, сборка11, имя автора и @dvizhoffline.
3. Открыть группу с установленным Telegram; проверить поведение без Telegram.
4. В авиарежиме скопировать адрес; автоматического перехода при входе нет.
5. Проверить крупный шрифт и возврат в Движ, не отправлять сообщения автоматически.

Android-обработчик, браузер, фактическая доступность/права входа в группу на
устройстве не тестировались. Адрес задан пользователем, владение не проверялось.
