### 2.2 Финальная палитра сайта — ЗАМЕНЯЕТ оранжевый `:root`/`theme-color`/`.btn-primary` из исходного `index.html`

Этот блок уже совпадает с патчем §4.1 прошлого сообщения; продублирую как **единственный действительный** источник цвета, чтобы оранжевая версия из сообщения «вебсайт» считалась отменённой. Положи в `<style>` вместо старого `:root` и старых правил кнопки.

```css
:root {
  color-scheme: light dark;
  --bg: #ffffff;
  --fg: #0B1A3C;
  --muted: #5A6478;
  --card: #F4F6FA;
  --accent: #0A3BFF;     /* электрический синий */
  --accent-2: #B7FF00;   /* лайм */
  --accent-3: #00E5FF;   /* циан */
  --border: #E1E6EF;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #0B1A3C;
    --fg: #F4F6FA;
    --muted: #AEB8CC;
    --card: #11224A;
    --accent: #3D6BFF;
    --accent-2: #B7FF00;
    --accent-3: #00E5FF;
    --border: #1E3366;
  }
}

.btn-primary {
  background: linear-gradient(135deg, var(--accent) 0%, var(--accent-3) 100%);
  color: #ffffff;
}
.btn-primary:hover { filter: brightness(1.08); }

.badge {
  border: 1px solid var(--border);
  background: var(--card);
  color: var(--fg);
}
.badge.hot {
  border-color: var(--accent-2);
  color: var(--fg);
  background: color-mix(in srgb, var(--accent-2) 14%, var(--card));
}
```

И в `<head>` оранжевый `theme-color` заменяется двойным брендовым (этот фрагмент из §2 прошлого сообщения **верен**, повторяю для полноты отмены оранжевого):

```html
<meta name="theme-color" media="(prefers-color-scheme: light)" content="#F4F6FA">
<meta name="theme-color" media="(prefers-color-scheme: dark)"  content="#0B1A3C">
<meta name="theme-color" content="#0B1A3C">
```
