# Продолжение проекта Орбитакт · 2026-11-05

## Почему работа перенесена в новый чат

Длинная Flutter-задача содержит исходный код, тесты, рисунки, сборочные
журналы и несколько промежуточных выпусков. У чата конечная длина рабочего
контекста; при её достижении предыдущий чат перестаёт принимать продолжение.
Чек-лист, контрольные ZIP и этот файл сохраняют состояние для следующего
чата, чтобы не восстанавливать задачу по памяти.

## Текущий статус

- Уровни шагов, воды и туалета внедрены по переданным порогам.
- Иллюстрации уровней уже находятся в `app/assets/ranks/` (14 файлов).
- Переданные Kotlin-скрипты сохранены в `docs/levels/supplied/` и адаптированы
  с проверкой обратной совместимости; полный аудит в `KOTLIN_REVIEW.md`.
- Экраны шагов, воды и туалета обновлены; узкие экраны и крупный текст
  покрыты тестами.
- Релиз 3.10.0+24 и исходный ZIP подготовлены. Подробности и хеши —
  `RELEASE_REPORT.md`.
- GitHub branch пока не менялась. ZIP предназначен для загрузки исходников.
- Открыта только ручная приёмка приложения на настоящем телефоне/лаунчере.
